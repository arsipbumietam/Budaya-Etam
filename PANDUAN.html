Dua versi dengan tujuan berbeda. HTML pratinjau hanya menyimpan data percobaan di browser yang sama. Aplikasi server menyimpan data dalam basis data dan menerapkan pemeriksaan hak akses di server. Keduanya tidak berbagi data. Jangan menggunakan HTML pratinjau untuk mengumpulkan data masyarakat.

1. Menjalankan aplikasi server

Ekstrak seluruh isi Website_BPK_Kaltim_Lengkap.zip. Pada Windows, pasang Python 3.11 atau lebih baru dan aktifkan pilihan Add Python to PATH. Buka folder hasil ekstraksi, lalu klik dua kali MULAI-WINDOWS.bat.

Instalasi pertama memerlukan internet untuk memasang paket. Setelah aplikasi berjalan, browser akan dibuka. Alamat lokalnya:

http://127.0.0.1:8000

Apabila browser belum terbuka otomatis, salin alamat tersebut ke browser. Biarkan jendela server tetap terbuka saat website digunakan. Tekan Ctrl+C untuk menghentikannya. Pada macOS/Linux, jalankan bash mulai.sh.

Data berada di folder data. Menutup server tidak menghapus data. Jangan menghapus folder ini saat memperbarui file aplikasi.

3. Menerbitkan konten dan Cinebudaya

Pilih Konten & Cinebudaya → Tambah konten. Isi jenis konten, judul, kategori, ringkasan, dan isi. Pilih gambar sampul dari pustaka atau unggah gambar. Tambahkan PDF, sumber, dan kredit bila diperlukan. Pilih Draf untuk menyimpan tanpa menayangkannya, atau Terbit untuk menampilkan kepada pengunjung. Klik Simpan konten.

Untuk Cinebudaya, pilih jenis Cinebudaya dan kategori Film, Cerita, atau Dialog. Masukkan tautan YouTube, Vimeo, atau MP4/WebM yang berizin untuk tayangan. Cerita dapat ditulis langsung pada isi konten. Video tidak diunggah langsung ke server pada versi ini.

Katalog awal berlabel Konten contoh. Tidak ada film atau dokumen resmi yang direka. Ganti dengan materi balai dan lengkapi hak tayangnya sebelum dipublikasikan.

4. Memproses permohonan

Pengunjung memilih layanan dan mengisi formulir. Setelah berhasil, sistem memberi nomor tiket dan kunci lacak. Simpan keduanya melalui tombol simpan bukti TXT. Kunci lacak tidak muncul kembali di panel pengelola.

Pengelola membuka Permohonan, memilih pengajuan, lalu menetapkan petugas, status, dan tanggapan. Tanggapan untuk pemohon terlihat melalui pelacakan; Catatan internal tidak ditampilkan kepada pemohon. Pengguna dapat menambahkan tanggapan/lampiran sebelum permohonannya ditutup. Status tersedia: Diterima, Diverifikasi, Perlu Perbaikan, Diproses, Selesai, dan Ditolak.

Lampiran permohonan pada server bersifat privat. Jangan menaruh lampiran pribadi di menu Gambar & PDF karena pustaka tersebut untuk publik. Pemberitahuan email/WhatsApp otomatis belum diintegrasikan; pemohon memeriksa perkembangan melalui portal.

5. Mengubah logo, identitas, dan warna

Logo utama menggunakan logo Kementerian Kebudayaan Republik Indonesia. Pengaturan awal memakai sumber gambar daring, sehingga memerlukan internet sampai salinan lokal tersedia. File ambil_logo.py mencoba menyimpan salinan logo ketika aplikasi dimulai. Bila sumber daring tidak dapat diakses, unggah PNG logo resmi melalui Identitas Website.

Pada menu yang sama, lengkapi alamat, telepon, email resmi, profil, sejarah, visi/misi, struktur organisasi, dan kebijakan data. Informasi tersebut belum diisi secara spekulatif. Untuk mengganti warna, buka Warna & Tampilan, pilih palet, lalu klik Simpan warna. Warna logo tidak ikut diubah.

6. Menambah akun dan mengganti password

Masuk sebagai Febryanto, lalu pilih Pengguna & Admin → Tambah pengguna. Isi username, nama, peran, dan kata sandi. Superadmin mengelola semua fitur; Admin mengelola portal tetapi tidak mengelola akun; Editor mengelola konten dan berkas publik; Petugas menangani permohonan.

Ganti password awal melalui Akun Saya. Gunakan minimal 10 karakter berisi huruf, angka, dan simbol. Jangan menggunakan password pratinjau sebagai password akun lain. Akun sendiri tidak dapat dihapus melalui panel.

7. Ekspor dan cadangan

Ekspor Data menghasilkan CSV/JSON untuk rekap dan ZIP data lengkap bagi Superadmin pada server. Ekspor ini tidak menyertakan hash password atau sesi, sehingga bukan cadangan untuk memulihkan login.

Untuk cadangan penuh, hentikan server lalu jalankan python backup.py --server-stopped. ZIP tersimpan pada folder backups. Cadangan mengandung data rahasia; simpan secara aman dan jangan unggah ke halaman publik. Cara pemulihan tercantum pada README.md.

8. Saat akan dipublikasikan

Website belum terpasang pada domain atau hosting. Berikan seluruh paket kepada pengelola teknologi informasi balai. Petunjuk teknis tersedia pada DEPLOY.md. Server perlu HTTPS, penyimpanan permanen, konfigurasi lingkungan produksi, kata sandi unik, serta pengujian keamanan pada lingkungan yang dipakai.

Sebelum peluncuran, sahkan identitas, standar layanan, kebijakan penggunaan data, dan materi publikasi; ganti atau hapus konten contoh. Barulah nonaktifkan mode peninjauan melalui Identitas Website. Sistem memeriksa pergantian sandi serta kelengkapan alamat, email, dan telepon sebelum mode tersebut dinonaktifkan.

Apabila menemui kendala

HTML tampak sebagai kode: simpan file lalu buka dengan Chrome/Edge, bukan editor teks. Logo tidak terlihat: pastikan internet aktif atau unggah logo lokal melalui admin. Data pratinjau tidak tersimpan: hindari mode privat dan periksa izin penyimpanan browser; gunakan server untuk data penting. Server belum terbuka: baca pesan pada jendela MULAI-WINDOWS.bat dan pastikan pemasangan paket selesai. Halaman tidak terhubung: jalankan kembali server lalu buka alamat lokal di atas.
